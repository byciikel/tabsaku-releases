Tabsaku

Catatan keuangan yang membaca email bank-mu, dan semuanya tetap di HP-mu.

Unduh APK terbaru

Cara memasang

  1. Buka tombol di atas dari HP Android (8.0 atau lebih baru), lalu unduh file tabsaku-….apk.
  2. Kalau HP bertanya, izinkan browser-mu memasang aplikasi dari sumber ini.
  3. Buka file APK-nya dan pilih Pasang.

Periksa file-nya

Setiap rilis mencantumkan SHA-256 file APK-nya. Cocokkan sebelum memasang kalau kamu ingin yakin file-nya utuh.
